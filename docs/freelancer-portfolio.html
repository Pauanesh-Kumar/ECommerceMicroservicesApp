E-Commerce Microservices

A .NET backend exploring service boundaries, event-driven commerce, resilient integrations and data ownership.

.NET 10   /   Kafka   /   PostgreSQL   /   MongoDB   /   Redis

Project README   |   Architecture and validation   |   Download PDF

Work in progress. All solutions build with warnings and local service health checks pass; end-to-end flows remain unverified. This is an architectural portfolio, not a claim of production readiness.

Seven focused services

Identity & catalog

User registration and authentication alongside a MongoDB-backed product catalog.

Cart & orders

Redis-backed carts initiate order creation through an HTTP client. Order creation records an idempotency key and outbox message.

Payments

Kafka-based processing, PostgreSQL persistence and a signature-verified Razorpay webhook endpoint.

Notifications & analytics

Event consumers support notifications, event storage and a reporting projection.

Design highlights

Service boundaries

API, application, domain and infrastructure projects make responsibilities explicit.

Event-driven integration

Kafka consumers and outbox publishers support asynchronous communication across service boundaries.

Delivery & observability

Docker Compose, a YARP gateway and tracing-related packages form a basis for local deployment and diagnostics.

Next steps

Resolve build and dependency warnings, secure configuration and Git history, and verify service integrations, authorization and deployment using automated tests.
